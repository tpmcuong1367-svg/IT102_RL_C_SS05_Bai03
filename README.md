Đây là hàng đợi FIFO nên thứ tự là yêu cầu bắt buộc, loại ngay Swap with Last. Soft Delete chính là kiểu để dữ liệu rác lại trong mảng, đúng điều gây ra sự cố hiện tại. Còn nhược điểm O(n) của Shift Array không đáng kể vì n ≤ 100, nên cùng lắm chỉ vài chục phép gán mỗi lần hủy.

Luồng thực thi Nhập n, kiểm tra 0 ≤ n ≤ 100 (sai thì nhập lại). Nhập từng bệnh nhân, tuổi và BHYT đều có kiểm tra và yêu cầu nhập lại. STT tự cấp theo thứ tự đăng ký.
